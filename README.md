# Signals and Systems: Audio Processing

Python experiments developed for the Signals and Systems course at Sharif University of Technology, covering Fourier analysis, frequency-domain manipulation, system identification, and audio restoration.

## Experiments

| Notebook | Focus |
| --- | --- |
| [Frequency shifting](notebooks/frequency_shifting.ipynb) | Partial spectrum shifts, audio mixing, and inverse shifting |
| [Fourier analysis](notebooks/fourier_analysis.ipynb) | Direct DFT/IDFT implementation, NumPy comparison, and sampling effects |
| [Inverse filtering](notebooks/inverse_filtering.ipynb) | Frequency-response estimation and regularized channel inversion |
| [Audio denoising](notebooks/audio_denoising.ipynb) | Noise estimation, notch filtering, and spectral subtraction |

## Repository structure

- `notebooks/`: independent experiments with plots and audio playback.
- `data/audio/`: six input WAV recordings supplied with the course project.
- `docs/report.pdf`: original technical report in Persian.
- `outputs/`: audio files regenerated by the notebooks and excluded from version control.

## Run

Use Python 3.10 or newer. From the repository root:

```bash
python -m pip install -r requirements.txt
python -m jupyter lab
```

Select a Python environment containing these dependencies and run any notebook from top to bottom. No execution order between notebooks is required. The notebooks retain the original experimental methods; saved plots and embedded audio are omitted to keep the repository compact.
